# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting on this repository. Include the affected component, reproduction steps, impact, and any suggested mitigation.

Do not test against production systems, access data that is not yours, degrade service, or move funds. We will acknowledge a complete report as promptly as practical and coordinate remediation and disclosure.

This scaffold does not provide live transaction execution. That status does not make unsafe behavior or accidental credential exposure appropriate for public disclosure.

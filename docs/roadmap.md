# Roadmap

1. Verify Robinhood Chain network facts and select providers from authoritative sources.
2. Implement and adversarially test the Robinhood Chain adapter and one narrowly scoped action.
3. Prove private execution, reconciliation, abuse controls, and operational monitoring.
4. Extend the same core to Base, then BNB Chain, with chain-specific policy and tests.

Each launch remains gated by security evidence. Dates and provider integrations are intentionally not promised here.

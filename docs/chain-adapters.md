# Chain adapters

Adapters isolate verified network facts and chain-specific policy while preserving one core lifecycle. Onboarding a network requires authoritative chain identification, RPC/finality behavior, approved assets and targets, provider selection, gas policy, feature-specific tests, and operational security review.

Robinhood Chain is the first target. Base and BNB Chain are planned extension points. Their current adapters contain no chain ID, RPC URL, router, bridge, token, contract, or relayer assumption and reject execution explicitly.
